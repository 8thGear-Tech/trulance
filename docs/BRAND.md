# Trulance brand — quick reference for the website

## Logo

- Wordmark: lowercase **trulance** in Bricolage Grotesque ExtraBold with an **orange circular full stop**.
- Files: `public/brand/trulance-logo-primary.svg` (navy, for light backgrounds), `trulance-logo-reversed.svg` (white, for navy backgrounds), `trulance-icon-navy.svg`, `trulance-icon-orange.svg`.
- Clear space = height of the "t". Minimum width 96 px; icon 24 px.
- Don't stretch, rotate, recolor, add effects, retype it, or place the primary logo on orange.

## Colour (Tailwind tokens in `src/app/globals.css`)

| Token | Hex | Use |
|---|---|---|
| `ink` | #101828 | Primary text, dark sections, primary dark buttons |
| `signal` | #FF5B1F | Accent: the dot, primary CTA buttons, highlights on navy. ~10% of a layout |
| `ember` | #C2410C | Orange **text** on light backgrounds (accessible contrast) |
| `slate` | #475467 | Secondary text |
| `paper` | #F6F4EF | Page background |
| `line` | #E4E2DC | Borders |
| `mist` | #D0D5DD | Secondary text on navy |

## Type

- **Bricolage Grotesque** (variable, self-hosted) for everything. Headlines ExtraBold, tight tracking (`tracking-tightest`, −3.5%).
- **JetBrains Mono** for eyebrows, labels, numbers and tags (uppercase, wide tracking).

## Voice

Confident, plain-spoken, warm. Short sentences. Headlines end with the orange full stop. No invented stats, testimonials or client logos.
